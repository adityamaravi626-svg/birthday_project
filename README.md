## Birthday Edition

A personalized interactive birthday project created.

### Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Plotly
- Pillow

### Project Features

- 🌸 Interest Profile
- 🤖 Personality Prediction
- 🍕 Food Recommendation
- 🧠 Interactive Quiz
- 🔮 Birthday Prediction
- 📸 Trio Memories
- 🎂 Birthday Experience

  ### Development

The project is developed using Google Colab and deployed using Streamlit Community Cloud.
